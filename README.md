# Edu Nexus National

The goal is to ensure that this becomes a centralized  NATIONAL EDUCATION DIGITAL ECOSYSTEM where each school is independently operating.

It must be serving as a large scale centralized system for all schools and flexibly structured with configurations for every school.

Each individual school must be independently operational.
The various models will be provided later
